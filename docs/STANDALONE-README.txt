FLIGHTOLED GUARDIAN v0.3.0 — Standalone Windows x64 / Bağımsız Windows x64

ENGLISH

Extract the complete ZIP to a stable folder and run FlightOLEDGuardian.App.exe.
Keep every file and subfolder together. Do not copy this app into MSFS Community.
Close an existing Guardian instance from its tray menu before starting this copy.
Windows 10/11 x64 is required. The .NET 8.0.34 runtime is included; no separate
.NET download or development environment is needed.

Choose English or Türkçe on first launch. Default activation is 7,000 FT AGL and
60 seconds idle. The cycle is 9 minutes normal display (including a final
10-second countdown) and 1 minute black. The selected monitor, timings and
profile can be changed in Protection. Start with MSFS is optional (EXE.xml).
Keyboard/mouse/significant supported joystick input wakes the screen.
Emergency shortcut: Ctrl+Alt+F12; fallback Ctrl+Shift+F12.

Live MSFS telemetry requires an installed official x64 native SimConnect client.
The Microsoft SDK DLL is not redistributed. If automatic detection does not find
your installed client, select it in Settings. Mock lab works without a simulator.
Guardian reads telemetry; it does not write aircraft controls.

Generate a SimBrief OFP first, enter Alias or Pilot ID and click Fetch.
No SimBrief password is requested. TOD is planned route TOD, not live FMS/VNAV TOD.
Identity is masked by default and always hidden in streaming mode; the local
settings file is not encrypted.

PUBLIC PREVIEW: live MSFS cycling and physical capture-card/OBS behavior remain
unverified. Cloned HDMI can include the black overlay. Record a test with your
exact capture arrangement. OLED burn-in prevention is not guaranteed.
Screenshots supplied with the listing show labelled mock/test data.

Settings and reports: %LOCALAPPDATA%\FlightOLEDGuardian
Disable Start with MSFS before moving/removing the program. If you move it while
auto-launch is enabled, save that setting again to refresh the executable path.

Source and feedback: https://github.com/erencevikk/FlightOLEDGuardian
Please include version, mock/live mode, AGL/MSL settings and reproducible steps.
Remove SimBrief identity and personal data from screenshots/logs before sharing.

TÜRKÇE

ZIP dosyasının tamamını sabit bir klasöre çıkartıp FlightOLEDGuardian.App.exe
dosyasını açın. Bütün dosya ve alt klasörleri birlikte tutun. Community klasörüne
atmayın. Çalışan Guardian örneğini tepsi menüsündeki Çıkış ile kapatın.
Windows 10/11 x64 gerekir. .NET 8.0.34 dahildir; ayrıca .NET veya geliştirme
ortamı indirmeniz gerekmez.

İlk açılışta English veya Türkçe seçin. Varsayılan eşik 7.000 FT AGL ve 60 saniye
hareketsizliktir. Döngü 9 dakika normal görüntü (son 10 saniyede geri sayım) ve
1 dakika siyahtır. Monitör, süre ve profil Koruma bölümünden değiştirilebilir.
MSFS ile başlatma isteğe bağlıdır (EXE.xml). Klavye/fare/desteklenen joystick'teki
belirgin hareket ekranı açar. Acil kısayol Ctrl+Alt+F12; alternatif Ctrl+Shift+F12.

Canlı MSFS telemetrisi için kurulu resmî x64 native SimConnect istemcisi gerekir.
Microsoft SDK DLL'si yeniden dağıtılmaz. Otomatik algılama bulamazsa kurulu resmî
istemciyi Ayarlar'dan seçin. Test laboratuvarı simülatör olmadan çalışır.
Guardian telemetri okur; uçuş kumandalarına yazmaz.

Önce SimBrief OFP oluşturun; Alias veya Pilot ID girip planı getirin. Şifre
istenmez. TOD planlanan rota değeridir; canlı FMS/VNAV TOD'u değildir. Kimlik
varsayılan maskeli, yayın modunda daima gizlidir; yerel ayar dosyası şifrelenmez.

GENEL ÖNİZLEME: Gerçek MSFS koruma döngüsü ve fiziksel capture kartı/OBS davranışı
henüz doğrulanmadı. Klonlanmış HDMI siyah katmanı taşıyabilir. Kendi düzeninizde
test kaydı alın. OLED yanığını önleme garantisi verilmez. İlan görüntülerinde
açıkça etiketlenmiş mock/test verisi gösterilir.

Ayarlar/raporlar: %LOCALAPPDATA%\FlightOLEDGuardian
Programı taşımadan/silmeden önce MSFS ile başlatmayı kapatın. Otomatik başlatma
açıkken taşıdıysanız ayarı yeniden kaydedip yürütülebilir dosya yolunu yenileyin.
