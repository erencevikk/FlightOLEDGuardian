# v0.2 verification — 17 November 2026

Requested fixes: language selector, MSFS EXE.xml startup, SimBrief Alias/Pilot ID import, readable dropdowns, native SimConnect loading, visible mock numbers.

## Validation

- Release build with warnings treated as errors.
- Core scheduling regression suite retained.
- Fake HTTP tests cover Alias escaping, Pilot ID validation, OFP metadata, stable identity, missing TOD, error responses, cancellation and oversized data. No live user OFP was fetched because no SimBrief identity was supplied.
- Temporary EXE.xml tests preserve unrelated addons, reject malformed/global-disabled configuration, deduplicate Guardian and create backups. Real MSFS configuration was read for discovery but not modified.
- Full-app UI checks switch Turkish/English at runtime, preserve profile and monitor selection, inspect the actual dark popup containers and verify both numeric mock bindings. Rendered dropdown, protection and mock pages were visually inspected.
- Installed native MSFS 2024 SDK DLL loaded successfully. A 20-second read-only connection probe found no active MSFS connection. Desktop window inventory showed no running simulator window. Live telemetry remains pending.
