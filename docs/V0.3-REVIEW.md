# v0.3.0 user review and validation — 17 November 2026

## Delivered

- English factory default, independent English/Türkçe question on first launch, saved choice respected.
- Default IFR 7,000 FT **AGL**; former built-in MSL default migrates. Explicit custom MSL profiles remain available.
- Alias/Pilot ID hidden by default with a real password field. Streaming always masks both entry points. Import still receives the original identity. Plain and URL-encoded identity are redacted from import errors. This is display privacy, not encryption of the local settings file.
- Update check once on every process startup, including tray startup; manual check and current version in Settings. No blocking dialog, automatic download or installation. Latest stable GitHub release only, numeric version comparison, timeout/size limits and restricted release-page links. No flight telemetry or SimBrief identity is sent to the update feed.
- Aircraft/shield icon embedded in the Windows EXE, title bar, application header, tray and Setup. Multi-resolution ICO includes 16–256 px.
- Normal minimize keeps the taskbar entry. The dedicated tray button and window close still hide to tray. Tray double-click restores the window.
- Flight action buttons above the telemetry cards. Visible explanation for disconnected, suspended, ground, capture-gated and idle-wait states.
- Single EXE per-user Setup with English/Türkçe selection, Start menu link, optional desktop link and Windows uninstall entry. Stable installation path; no administrator elevation. Existing settings/reports stay separate. Embedded payload extraction stages files and restores previous files on copy failure. Installer requires Windows .NET Framework 4.x; application requires .NET 8 Desktop Runtime x64. Missing runtime opens Microsoft's download page after Install is clicked.
